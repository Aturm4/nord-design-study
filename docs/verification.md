## Что исправлено по результатам просмотра

- Неверное соотношение сторон миниатюр из-за HTML-атрибутов высоты.
- Вертикально перевёрнутые UV-координаты этикетки GLB.
- Слишком большой центральный объект и его касание заголовка.
- Пересечение мобильного CTA с объектом: первый экран переведён в последовательную вертикальную раскладку.
- Выход правого заголовка за границу экрана на 320 px.
- Цвет тени у синего варианта упаковки.
- Деление на ноль при совпадении указателя и центра декоративного объекта.
- Согласованы версии Three.js и peer-зависимости model-viewer.

## Дополнительные проверки

`npm run check` — пройдено: синтаксис встроенного JavaScript, наличие локальных ассетов, заголовки GLB, уникальные ID и существующие цели якорей. `node --check` для сервера и генератора модели — пройдено.

Системный `prefers-reduced-motion` учтён в CSS и JavaScript, включая изменение настройки во время работы страницы. Его реализация проверена по коду; принудительная эмуляция системного media query в браузере не выполнялась. Ручной режим без движения проверен интерактивно. Размеры телефона и планшета проверены через viewport браузера, без физических устройств и отдельной проверки Safari.
